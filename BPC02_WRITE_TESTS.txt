BPC02 — MODBUS WRITE FUNCTION VERIFICATION CHECKLIST
====================================================
(ISOLATED BENCH TEST ONLY — DO NOT RUN ON A LIVE PUMP INSTALLATION)

CONNECTION SETTINGS (ALREADY VERIFIED)
--------------------------------------
Connection: Serial COM4 (RS485) — later repeat over Samin ES 487 Modbus TCP
Protocol:   Modbus RTU
Serial:     9600 baud, 8 data bits, No parity, 1 stop bit (9600 8N1)
Slave ID:   1
Addressing: Zero-based decimal PDU address (offset = 0)

CRITICAL SAFETY RULES BEFORE STARTING
-------------------------------------
1. ISOLATED BENCH ONLY: Disconnect ALL pump motor power / contactors /
   inverter run outputs so no physical motor or valve can energize.
2. RECORD ORIGINAL VALUES FIRST: Always read back before writing, and
   immediately restore every changed register to its original value.
3. WATCH FOR THE BPC02 4-BYTE REJECTION QUIRK:
   Previously, unsupported functions (FC02, FC04) returned a 4-byte frame
   with valid CRC (e.g. 01 02 81 E1, 01 04 01 E3). If a write function
   returns a 4-byte frame (01 05 XX XX, 01 06 XX XX, 01 0F XX XX, or
   01 10 XX XX), that function code is NOT supported by BPC02 firmware.
4. DO NOT WRITE TO ADDRESS 4195 (Modbus Slave ID) during these tests, or
   you will lose communication at Slave ID 1.
5. DO NOT WRITE TO READ-ONLY STATUS REGISTERS (Coils 0–33, Words 0–45, 80).


====================================================
SUMMARY OF ALL DOCUMENTED WRITABLE BPC02 REGISTERS
====================================================

A. Manual Mode & Live Output Control (BPC-02.pdf pp. 26–28)
   - Word 99      : Multi Function Register (1234 = Enter Manual, 0 = Auto)
   - Coils 50–59  : Output 0–9 Manual (0 = OFF, 1 = ON)
   - Words 50–51  : Analog Output 0–1 Manual (0–500, unit 0.1 Hz -> 0.0–50.0 Hz)

B. Hardware Configuration Coils (BPC-02.pdf pp. 26–27) — DANGEROUS ON LIVE SITE
   - Coils 4096–4101 : Pump 1–6 Activation (0 = Disable, 1 = Enable)
   - Coil  4106      : Control Phase Activation (0 = Disable, 1 = Enable)
   - Coil  4107      : OFF Changing Activation (0 = Disable, 1 = Enable)
   - Coil  4108      : Time Changing Activation (0 = Disable, 1 = Enable)
   - Coil  4109      : Reserve Automatic Activation (0 = Disable, 1 = Enable)
   - Coil  4110      : Reserve Automatic Type (0 = NO, 1 = NC)

C. Hardware Configuration Holding Registers (BPC-02.pdf p. 28) — DANGEROUS ON LIVE SITE
   - Word 4173       : Control Status (0–1)
   - Word 4175       : Sleep Gap (1–100, unit 0.01 Bar)
   - Word 4177       : Auto Service Off Time (1–9999, Hour)
   - Word 4178       : Auto Service On Time (1–999, 0.1 Sec)  [PDF typo: 417B]
   - Word 4179       : Auto Service Interval (1–99, Min)
   - Words 4180–4183 : MFI1–4 Type (0:Disable, 1:PS, 2:MP, 3:EMG, 4:CP, 5:FL) [PDF: 41B0]
   - Words 4184–4186 : MFO1–3 Type (0:Disable, 1:E Valve, 2:Fan, 3:Alarm, 4:DC3, 5:MC3)
   - Word 4195       : ModBus Address (Slave ID — DO NOT CHANGE during bench test)

CANDIDATE MODBUS WRITE FUNCTION CODES TO IDENTIFY
-------------------------------------------------
- Coils (Bit table):
    FC05 (0x05) = Write Single Coil (ON = 0xFF00, OFF = 0x0000)
    FC15 (0x0F) = Write Multiple Coils
- Holding Registers (Word table):
    FC06 (0x06) = Write Single Register
    FC16 (0x10) = Write Multiple Registers

TEST W01 — ENTER & EXIT MANUAL MODE (ADDRESS 99)
------------------------------------------------
Goal: Confirm whether Address 99 uses FC06, FC16, or both, and confirm
      whether Address 4173 (Control Status) reflects Manual vs Auto mode.

Step W01-1 (Baseline read):
  Read FC03 Addr 99 Qty 1   -> TX: 01 03 00 63 00 01 74 14  (expected 0)
  Read FC03 Addr 4173 Qty 1 -> TX: 01 03 10 4D 00 01 10 DD  (expected 0)
  Rx (99):
  Rx (4173):

Step W01-2 (Enter Manual Mode via FC06: write 1234 = 0x04D2 to Addr 99):
  Function: 06 — Write Single Register
  Address:  99 (decimal)
  Value:    1234
  Exact TX: 01 06 00 63 04 D2 FB 49
  Expected standard reply: echo of request (01 06 00 63 04 D2 FB 49)
  Rx:
  Did controller LCD switch to Manual Mode? (Yes/No):
  Read back FC03 Addr 99 Qty 1   -> Rx:
  Read back FC03 Addr 4173 Qty 1 -> Rx:  (Did 4173 change from 0 to 1?)

Step W01-3 (ONLY if FC06 failed — try FC16 / 0x10):
  Function: 16 (0x10) — Write Multiple Registers
  Address:  99, Quantity: 1, Value: 1234

TEST W03 — MANUAL DIGITAL OUTPUT COIL 50 (OUTPUT 0 MANUAL)
----------------------------------------------------------
Precondition: Controller is in Manual Mode (99 = 1234). NO loads connected!
Goal: Confirm whether Coils 50–59 accept FC05, FC15, or both, and confirm
      Output 0 relay / Coil 0 status follows Coil 50.

Step W03-1 (Turn ON Coil 50 via FC05):
  Function: 05 — Write Single Coil, Addr 50, Value ON (0xFF00)
  Exact TX: 01 05 00 32 FF 00 2D F5
  Expected standard reply: echo (01 05 00 32 FF 00 2D F5)
  Rx:
  Did physical Relay / LED Output 0 turn ON? (Yes/No):
  Read back FC01 Addr 50 Qty 10 -> Rx:
  Read back FC01 Addr 0 Qty 10  -> Rx: (Did Bit 0 Output 0 Status turn 1?)

Step W03-2 (Turn OFF Coil 50 via FC05):
  Function: 05 — Write Single Coil, Addr 50, Value OFF (0x0000)
  Exact TX: 01 05 00 32 00 00 6C 05
  Rx:
  Did Relay / LED Output 0 turn OFF? (Yes/No):

Step W03-3 (ONLY if FC05 failed — try FC15 / 0x0F):
  ON  -> Exact TX: 01 0F 00 32 00 01 01 01 D6 93   Rx:
  OFF -> Exact TX: 01 0F 00 32 00 01 01 00 17 53   Rx:

Step W03-4 (EXIT MANUAL MODE immediately!):
  Write 0 to Addr 99 -> Exact TX: 01 06 00 63 00 00 79 D4
  Rx:
  Confirm controller is back in Automatic Mode.


TEST W04 — SAFETY INTERLOCK CHECK (MANUAL WRITE IN AUTOMATIC MODE)
------------------------------------------------------------------
Precondition: Controller is in AUTOMATIC Mode (Addr 99 = 0).
Goal: Know whether BPC02 blocks manual output writes when NOT in manual mode.

  Send FC06 Addr 50 = 50 -> Exact TX: 01 06 00 32 00 32 A9 D0
  Rx:
  Read back FC03 Addr 50 Qty 1 -> Rx: (Did it stay 0 or change to 50?)
  If it changed to 50, immediately restore 0: 01 06 00 32 00 00 28 05
