  Username : admin

2. CLIENT ACCESS — OPERATOR / اپراتور بهره‌بردار (دسترسی کاربری)
--------------------------------------------------------------------------------
  Username : operator
  Password : Pump@1234
  Role     : اپراتور (OPERATOR)
  Access   :
    - Default policy: STRICTLY READ-ONLY (cannot modify or write anything)
    - Live monitoring (pressure, setpoint, operating mode, drivers, tank, voltages)
    - Read-only view of pumps, run times, digital I/O, and controller settings
    - Individual write & feature permissions (Setpoint, Pump/Drive ON-OFF,
      Reset Pump Error, Control Status, Hardware Menu sections, JSON Export/Import,

      individually by the Administrator via «دسترسی های اپراتور»
