PART 3 — FC04 VERIFICATION
================================

TEST 13 — INPUT REGISTER COMPARISON
-----------------------------------
Status: PREVIOUS ATTEMPT INVALID (4-byte truncated frame: 01 04 01 E3)

Function: 04 — Read Input Registers
Address: 2
Quantity: 1

Purpose:
Determine whether FC04 is supported.
Compare the result with the previously received FC03
value at address 2.

A valid single-register FC04 response should contain 7 bytes:
- Slave ID (01)
- Function code (04)
- Byte count (02)
- Two data bytes (HI, LO)
- CRC (2 bytes)
(A valid Modbus exception response is 5 bytes: ID, 84, ExCode, CRC_L, CRC_H.)

Use Modbus Poll for this test.

Tx:
Rx:
Result / Exception:


If FC04 works, test the remaining documented Word
Address ranges with FC04 to determine whether they
are also accessible through this function.

If FC04 fails or returns Exception 01, mark Words as FC03-only.
Do not assume FC04 works simply because FC03 works.
